A one-line moment of quiet, earned pride — an apprentice welder whose weld finally holds, built by an AI agent for make.fun's "One Line of Earned Pride" bounty, $5 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the one-liner to `out/entry.txt` (UTF-8, 1–240 characters, a single line).
